# Ishiki user guide

Ishiki is a private-by-default personal operating system for commitments,
money, health, events, study, and work. It is not emergency, medical, legal, or
financial advice. Verify important dates, balances, and provider imports
against their authoritative source.

## Getting started safely

Sign in only on a trusted device. Use a unique password and sign out on shared
devices. Your private workspace remains private unless a feature clearly asks
you to share it. Household membership does not make health, tax/HELP, or
integration credentials shareable.

Enter information manually or connect a supported provider. Check imported
records after each sync. Calendar event cost remains Ishiki-only. Medical
events are private by default, and full forwarding requires explicit
per-event consent. Provider delays or outages can leave information stale;
the displayed source and sync state should be checked before acting.

## Handling errors

Retry ordinary network failures once connectivity returns. Avoid creating
duplicates while an import says it is queued or retrying. If a sync repeatedly
fails, disconnect it if safe and contact support with the time, feature, and
visible error category. Never send passwords, tokens, medical documents,
financial statements, or full screenshots containing private records.

For suspected unauthorized access, sign out, rotate affected provider
credentials, and contact support immediately. For urgent health or safety
needs, use the appropriate emergency or professional service rather than
Ishiki.

## Accessibility and support

The web application is intended for keyboard, touch, zoom, and reduced-motion
use on responsive screens. Report a barrier with the page, task, browser,
assistive technology, and expected outcome, omitting private record contents.

Before relying on a release, read its release notes for changed behavior and
known limitations. Support can diagnose using timestamps and safe error
categories; support should never ask for your password or provider secret.
